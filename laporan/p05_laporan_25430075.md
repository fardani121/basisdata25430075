1. Tujuan Praktikum  
Memahami dan mengimplementasikan perintah Data Definition Language (DDL) lanjutan serta modifikasi struktur tabel dalam basis data relasional. Mampu menerapkan Constraint khusus seperti CHECK untuk memvalidasi batasan nilai data. Mampu mengatur ulang perilaku Foreign Key menggunakan opsi referensial yang sesuai untuk menjaga integritas data pada proyek Akademik dan Koperasi Mahasiswa (Kopma).

2. Ringkasan Teori  
Modifikasi struktur tabel menggunakan perintah ALTER TABLE memungkinkan pengembang untuk menambah, mengubah, atau menghapus kolom serta batasan (constraint) pada tabel yang sudah ada. Constraint CHECK digunakan untuk memastikan nilai yang dimasukkan ke dalam suatu kolom memenuhi kondisi logika tertentu. Selain itu, dalam relasi antar tabel, pengaturan Referential Integrity melalui klausa referensial memastikan konsistensi data antara tabel utama (induk) dan tabel anak, sehingga mencegah kegagalan integritas data pada sistem basis data.

4. Titik Analisis  
Penerapan constraint CHECK pada kolom numerik sangat krusial untuk mencegah masuknya data invalid secara logis yang dapat merusak integritas sistem. Sementara itu, pemilihan aksi referensial pada hubungan antar tabel berdampak langsung terhadap bagaimana sistem memperlakukan data ketika entitas referensi utamanya dimanipulasi atau dihapus dari sistem basis data.
