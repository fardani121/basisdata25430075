 ## 4. Jawaban Titik Analisis

* **Titik Analisis 1:** 
  Meskipun tombol pengontrol di XAMPP bertuliskan "MySQL", server yang sebenarnya berjalan adalah MariaDB[cite: 33]. Dokumentasi MySQL masih relevan untuk urusan perintah SQL dasar dan standar ANSI, namun kita harus beralih ke dokumentasi MariaDB ketika menghadapi masalah yang spesifik pada versi MariaDB 10.4, variabel sistem, galat bawaan, atau fitur *storage engine* seperti InnoDB dan Aria.

* **Titik Analisis 2:** 
  Saat mencoba masuk menggunakan perintah `mysql -u root` tanpa opsi `-p` setelah akun *root* diberi password, server menolak dengan pesan `ERROR 1045 (28000): Access denied for user 'root'@'localhost' (using password: NO)`[cite: 10, 11, 35]. Bagian paling akhir dari pesan galat tersebut, yaitu `(using password: NO)`, merupakan penanda utama yang memberitahu bahwa klien sama sekali tidak menyertakan password saat mencoba melakukan koneksi[cite: 11].

* **Titik Analisis 3:** 
  Akun kerja (`mhs_075`) tetap dapat melihat `information_schema` karena basis data tersebut berisi metadata sistem global yang bersifat publik dan diperlukan oleh semua pengguna terautentikasi untuk menjalankan kueri. Sebaliknya, akses ke basis data `mysql` ditolak dengan pesan `ERROR 1044 (42000)` karena akun kerja tidak memiliki hak istimewa (*privilege*) untuk mengakses tabel sistem yang menyimpan data sensitif pengguna. Perbedaan kodenya: `ERROR 1044` terjadi karena pembatasan hak akses (*authorization* pada objek tertentu), sedangkan `ERROR 1045` terjadi karena kegagalan proses masuk atau otentikasi identitas (*authentication*).

* **Titik Analisis 4:** 
  Mode `cookie` pada phpMyAdmin jauh lebih aman daripada mode `config` karena mode `cookie` mewajibkan pengguna mengetik ulang password secara langsung pada halaman login setiap kali sesi dimulai[cite: 8, 36]. Sebaliknya, mode `config` menyimpan password secara terang-terangan (*plain text*) di dalam berkas konfigurasi `config.inc.php`, yang sangat berbahaya karena dapat dibaca oleh siapa saja yang memiliki akses ke komputer tersebut.
